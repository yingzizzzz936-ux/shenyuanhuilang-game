========================================
  深渊回廊 · ABYSS CORRIDOR
  网页悬疑解谜游戏
========================================

【如何运行】
1. 双击 abyss_local.html 即可在浏览器中打开游戏
2. 推荐使用 Chrome / Edge / Firefox 浏览器
3. 游戏会自动保存进度，关闭后再打开可点"继续上次进度"

【关于图片】
游戏引用了 images/ 文件夹中的17张场景背景图。
如果 images 文件夹为空或图片缺失，游戏仍可正常运行，
只是背景会显示为纯黑色，不影响玩法和剧情。

如需添加背景图，请将以下17张图片放入 images/ 文件夹：
  corridor.jpg      - 走廊/开始界面
  mirror.jpg        - 镜之房间/画之房间
  radio.jpg         - 声之房间/黑暗房间
  elevator.jpg      - 电梯
  clocks.jpg        - 时间房间
  textroom.jpg      - 文字房间
  monitor.jpg       - 邮件房间/档案室/监控室
  church.jpg        - 告解室/真结局
  library.jpg       - 图书馆
  courtroom.jpg     - 审判庭
  choice.jpg        - 抉择房间
  dorm.jpg          - 宿舍/失忆结局
  morgue.jpg        - 停尸间/沉沦结局
  surgery.jpg       - 手术室
  phonebooth.jpg    - 电话亭
  finalcorridor.jpg - 最终走廊
  mentor.jpg        - 导师房间/记忆回廊/双生结局

【游戏提示】
- 共8个结局（A-H），其中H为真结局
- 通关结局B后解锁二周目
- 部分谜题需要联网搜索圣经章节、历史年份等
- 第二关四个按钮都是陷阱，正确做法是"什么都不做"
- 第四关不要按红色按钮
- 状态栏可查看线索、保存进度、切换音效

【音效说明】
游戏使用 Web Audio API 实时生成背景音乐和音效，
无需下载任何音频文件。首次点击页面后音效自动开启，
可点击状态栏"🔊 音效"按钮切换静音。
